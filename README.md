# IntelliBudget (Streamlit)
Run locally: `pip install -r requirements.txt && streamlit run app.py`

Deploy on Streamlit Community Cloud: push this folder to a GitHub repo, then at share.streamlit.io choose
"Create app", select the repo/branch, set the main file to `app.py`, and deploy.

Files: `app.py` (app), `model.json` (exported weights, vocabulary, calibrators, thresholds), `results.json` (acceptance metrics).
